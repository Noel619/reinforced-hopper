# Simulador de Autoelevador

Simulador 3D de autoelevador contrapesado para **aprender a manejarlo de forma realista**, hecho con
[three.js](https://threejs.org/) (gráficos) y [Rapier](https://rapier.rs/) (física).

> Proyecto independiente dentro de la rama `simulador-autoelevador`.

## Cómo jugar

```bash
cd simulador-autoelevador
npm install
npm run dev        # abre http://localhost:5173
```

Para generar una versión estática (carpeta `dist/`): `npm run build`.

## Modos

- **Escuela de manejo**: 8 lecciones guiadas con evaluación y estrellas.
- **Modo libre**: centro de práctica con racks, camiones, rampa, conos y generador de cargas.
- **Mi Almacén**: gestioná tu depósito, atendé camiones, ganá dinero y comprá mejoras.
